Claude 能做的，比大多数人以为的多得多。

这篇指南一次讲全：每个功能在哪找、怎么打开，外加一条你马上就能用的提示词。

过一遍，挑出适合你工作流的，今天就设置好。每一项只需几分钟，设置完之后每天都在回报你。

## 一、普通 Claude 里的隐藏功能

### 1. Projects——真正记得你是谁的 Claude

每次你新开一个 Claude 对话，它都从零开始。它不知道你的名字、你的工作、你的偏好——一无所知。多数人接受了这一点，每一次对话都重新解释一遍自己。

Projects 解决的就是这个问题。你建一个项目，上传你的文档，写好常设指令——Claude 会把这一切永久记住。下个星期再打开，它从你上次停下的地方接着来。

如果你从没用过 Projects，这是本文所有事里第一件该修的。

**示例项目指令（贴进 Project Instructions 栏）：**

```
你是我的内容研究助手。我做一份面向技术读者的
AI 和加密货币 newsletter。

始终假设我的读者懂基础。不要解释什么是 LLM、
什么是区块链。

当我发给你一个话题或一篇文章，你的任务是：
1. 找出最反直觉或最意外的 3 个角度
2. 找到我可能错过的、与近期事件的关联
3. 建议我怎么把它框成一个故事，而不是一篇摘要

语气：直接，不用企业腔，不用废话短语。
格式：短段落，除非我要求，否则不用列表。
永远不要用「好问题」或「当然可以」开头。
```

### 2. Artifacts（工件）——聊天窗口里跑起来的应用

很多人以为 Claude 只能产出文字，建不出真东西。错了。

Artifacts 是 Claude 在聊天里直接造出**能用的东西**。不是一段要你复制到别处的代码——是侧栏里的活产品。一个计算器、一个习惯打卡器、一个游戏、一个带图表的仪表盘。你打开它，点它，用它，全程不用离开对话。

SVG 图形、交互图表、Mermaid 图——都支持。免费版就有。大多数人从没试过。

**试试这条：**

```
给我做一个习惯打卡器，要能跑的网页应用。

我要追踪 5 个每日习惯。
每天可以逐个打勾。
每个习惯显示 7 天连续打卡计数。
漏掉一天，连续计数清零。

设计：深色背景，干净的极简风。
让勾选框点起来过瘾——每完成一个加一个小动画。

刷新页面后数据要还在。
```

### 3. 自适应思考——另一个层次的推理

大多数 Claude 用户从来没打开过它。Extended Thinking（扩展思考）是一种模式：Claude 在回答之前，把问题一步一步推理一遍——而你能看到全过程。

简单问题用不着它。复杂决策、战略分析、任何你想让 Claude 真正思考而不是模式匹配的场景——输出质量的差别是显著的。

打开它。问你一直在问的那个问题。对比一下答案。

**遇到真正的决定时用这条：**

```
我在两个选项之间做决定，我要你先仔细想清楚再回答。

选项 A：[描述选项 A]
选项 B：[描述选项 B]

我的处境：[你的背景、约束条件、什么对你最重要]

回答之前先把这些问题过一遍。想：
- 每个选项的第二层和第三层后果
- 我大概在情绪上高估或低估了什么
- 我可能缺了什么信息，而它足以改变这个决定
- 如果事情变糟，哪个选项的下行保护更好

然后给我你真实的推荐，带上你的推理。
```

### 4. Memory——知道你是谁的 Claude

打开 Memory 之后，Claude 会随时间给你建一份档案：你的工作、你的项目、你喜欢的沟通方式、你手头在做的事。

开一个全新的对话，它已经知道上下文。你再也不用自我介绍。

它默认是关的。大多数人不知道它存在。

**给 Claude 的自我介绍模板：**

```
我要你记住以下关于我的信息，以后不用再问：

我叫 [名字]。我在 [公司或项目] 做 [角色]。
我现在的主要重心是 [你在做的事]。
我的读者或客户是 [他们是谁]。

当我求助时，始终默认这个背景，除非我另有说明。
我偏好的沟通风格：[直接 / 详细 / 随意 / 正式]。
回复里让我烦的东西：[比如列表、冗长的开场白、
没完没了的免责声明]。

现在把这些全部存进记忆。
```

## 二、给 Claude 一个角色——一条提示词改变一切

Claude 不必是「一个 AI 助手」。给它一个具体的角色，它会完全入戏——它怎么追问你、在哪反驳你、什么问题不肯放过，全都变了。复制下面任意一条，粘到新对话的开头。

### 5. 个人心理治疗师

大多数人把 Claude 当成一台认同机器：描述一个问题，Claude 说「这听起来确实很难」，然后给出五条建议。

好的心理治疗不是这么做的。这条提示词让 Claude 更接近一位 CBT（认知行为疗法）治疗师——用提问代替给答案，用挑战你的想法代替认同你的想法。

适合那些你翻来覆去拿不定主意的决定、说不清道不明的焦虑、任何你需要一个清醒的局外人视角的时刻。

```
你是一位有 20 年经验的认知行为治疗师。
我要跟你说一件我正在挣扎的事。

你的做法：
- 不要立刻给建议。先通过提问帮我看清
  我自己的思维模式。
- 留意认知扭曲——灾难化、非黑即白、读心术、
  预言未来——发现了就指出来。
- 一次只问一个问题。别把我压垮。
- 当我通过你的提问自己得出结论，那才是目标。
  别把答案递给我。
- 温暖但诚实。我的想法明显扭曲时，不要顺着我说。
- 如果我看起来在回避某件重要的事，直接说出来。

不要用临床式的开场白。直接问我怎么了。
```

### 6. 毫不留情的导师

默认状态下，Claude 同意你。它给你的想法添砖加瓦，支持你的推理，寻找积极面。这几乎总是错的做法。

这条提示词把那个开关关掉。Claude 停止认同，开始压力测试。它找出站不住的假设、被漏掉的考量、你的计划会在哪一处断掉。

它让人不舒服。所以它有用。

```
你是一位毫不留情的诚实导师。你创过业，
也失败过多次。你看着上百个人满怀信心地
犯下同一批错误。

你的工作不是鼓励我——是在我付出昂贵代价之前，
保护我远离我自己的盲区。

规则：
- 当你认为我错了，直接反对我。具体说清为什么。
- 指出我没看见的东西，尤其是那些因为太希望
  计划成事而刻意回避的东西。
- 问我自己没想到要去问的难题。
- 如果某件事是个坏主意，就说它是坏主意。
  不要用「另一方面……」来找平衡。
- 每次回复的结尾，给我一件最重要的事：
  在往前走之前我应该想清楚的事。

我马上要分享一个想法。别客气。
```

### 7. 私人教练

通用的健身建议到处都是。它们不考虑你的日程、你的旧伤、你的器材、你真实的目标。

把你的真实数据给 Claude，它给你一个真实的计划。不是模板，不是任何健身网站上能找到的东西——一个围绕你的处境搭建的计划，而且你每周汇报效果之后它会调整。

```
你是一位专家级私人教练兼运动营养师。
我要你给我做一份完整的训练计划。

我的情况：
年龄：[年龄]
当前体重 / 身体成分：[详情]
目标：[减脂 / 增肌 / 提升耐力 / 一般健康]
可用器材：[健身房 / 在家 / 只有哑铃 / 等]
每周能训练的天数：[数字]
每次训练时长：[分钟]
伤病或限制：[详情或「无」]
当前体能水平：[初级 / 中级 / 高级]

给我做一份 12 周计划。给出每周的完整安排：
动作、组数、次数、组间休息。解释你为什么
这样安排——我要理解逻辑，不只是照做。
开始之后我每周汇报，你根据进展调整。
```

### 8. 演练一场艰难的对话

大多数人都是毫无准备地走进艰难对话的。他们知道自己想说什么，但不知道对方会怎么回。

Claude 来扮演对方。演得很真。它按那个人的方式回应，你的论据弱的时候它就顶回来，好结果你得自己挣。练过几轮之后，真刀真枪的那场会容易得多。

```
我要准备一场艰难的对话。
我需要你扮演对方，让我练习。

对方是谁：[描述——老板、客户、联合创始人等]
我要说的话：[你要提出或告知的内容]
难在哪：[你害怕什么 / 可能出什么问题]
这个人什么样：[性格、通常的反应、在乎什么]

整个对话过程中保持角色。按这个人真实的反应
来回应——不是我希望的反应。如果我说了什么
软弱或没有说服力的话，顶回来。

每轮交锋之后，短暂跳出角色，告诉我哪里起作用
哪里没用——然后回到角色里。结束时给我一份
完整复盘：我哪里做得好、要改什么、真对话里
最该记住的事。

从角色里开始。等我先开口。
```

### 9. 魔鬼代言人

你已经拿定主意。反对意见你全想过了。你确信无疑。

恰恰是这个时候，该让 Claude 来进攻这个决定。不是客气的顾虑，是完整的反方案：它失败的三种最现实的路径，那些因为你太希望它成事而看不见的东西。

现在花五分钟。在你承诺之前。不是之后。

```
我已经做了一个决定。我要你在我承诺之前，
把这个决定最强有力的反对理由建出来。

决定：[准确描述你打算做什么]
我的理由：[你为什么认为这是好主意]
我已经考虑过的：[你已经想过的反对意见]

你的任务：
- 把反对这个决定的最强案例建出来。
- 不要用优点来平衡。我已经相信它了——
  我需要的是反面论证。
- 找出我正在做的、可能是错的假设。
- 描述它失败或反噬的三种最现实的路径。
- 告诉我我可能低估了什么。
- 告诉我，要相信什么，这个决定才是一个
  真正的坏主意。

下狠手。如果这是个错误，我现在就要知道。
```

## 三、多数人不知道存在的产品功能

### 10. Claude in Chrome——看见你所见的 Claude

大多数人在一个单独的标签页里用 Claude，需要什么就手动复制粘贴。那是费劲的路。

Claude in Chrome 是一个浏览器扩展，让 Claude 完全看见你当前打开的标签页，并且能在上面操作：读页面、点链接、填表单、跳转新网址。你用大白话描述任务，然后走开就行。

**怎么装**：在 Chrome 应用商店搜 Claude for Chrome → 安装 → 用你的 Claude 账号登录。点扩展图标打开侧栏。现在 Claude 能看见并操作你打开的任何页面。

**给它的示例任务：**

```
我在一个职位列表页上。

把页面上每一个可见的职位都过一遍，提取：
职位名、公司名、薪资范围（如果显示）、
以及排名前三的要求。

给我建一张按薪资排序的对比表，从高到低。

如果有多页，点进下一页继续，直到覆盖所有结果。
```

### 11. Claude Cowork——住在你桌面上的 Claude

网页版 Claude 碰不到你的电脑。看不见你的文件。什么都得你手动粘贴。

Cowork 是一个桌面应用，让 Claude 直接访问你的文件系统：读你的真实文件、编辑文档、新建文件、整理文件夹——你什么都不用往聊天框里复制。

### 12. Scheduled Tasks——你睡觉时还在干活的 Claude

大多数人把 Claude 当成需要手动启动的东西：开个对话，输入请求，等输出，关标签页。

Scheduled Tasks 改变这个。你设置一次任务，Claude 就在你选的时间和频率上自动执行——不需要你触发。每天早上。每个星期一。每个小时。Claude 跑完，把输出存进你的文件夹。

**示例定时任务描述：**

```
每个工作日早上 7:30，做以下事情：
1. 搜索过去 24 小时最重要的 AI 和加密货币新闻
2. 挑出 5 条最关键的——聚焦令人意外、反直觉、
   或对建设者和投资者有真实影响的
3. 每条写：标题、两句话摘要、为什么重要
4. 把结果存成「brief-[日期].md」，放进
   我的 /briefs 文件夹

语气保持直接、分析性。不要废话。3 分钟内能读完。
```

### 13. Cowork 里的 Skills——像插件一样安装新能力

Skills 是预置的指令包，给 Cowork 里的 Claude 特定能力。不用每次都解释你要什么——装一次技能，Claude 就已经知道怎么处理那一类任务：做 PPT、处理 PDF，或者跑某个特定工作流。

把它想成手机上的应用。裸机能用。装上对口的应用，它能干的多得多。

**怎么找怎么装**：Cowork → Customize → Skills 查看已装列表。要加新的，点左侧栏的 Browse plugins → 找到插件 → 安装。插件自带的技能会自动出现在你的 Skills 标签页里，任务需要时 Claude 自动调用。

### 14. CLAUDE.md——每个会话自动读取的规则

在 Cowork 和 Claude Code 里，你可以在项目文件夹里建一个 CLAUDE.md 文件。每次会话开始，Claude 都会自动读它，不用你提醒。

你的代码规范。你的写作风格规则。你们公司有特定含义的术语。品牌语气指南。写一次，Claude 在那个项目的每一次会话里都照着做，永远。

**示例 CLAUDE.md：**

```
# 项目：AI Newsletter

## 项目简介
面向建设者和投资者的 AI 与加密货币周刊。
35,000 订阅者。语气直接、分析性、偶尔不敬。

## 写作规则
- 短段落。最多 3 句。
- 编辑内容不用列表。只用散文。
- 不用长破折号。用连字符或重组句子。
- 数字胜过形容词。写「省 3 小时」，
  不写「省大量时间」。
- 禁用词：delve、groundbreaking、game-changing、
  leverage（作动词）、utilize。
- 缩写可以用，鼓励用。

## 内容规则
- 假设读者知道 LLM 是什么。不解释基础。
- 用最意外或最反直觉的东西开头。
- 每篇文章都要有具体的「所以呢」——
  读者该做什么、该换个什么想法。

## 文件结构
- 草稿放 /drafts
- 已发布文章放 /published，
  文件名前缀：YYYY-MM-DD-标题.md
- 研究笔记放 /research
```

### 15. Claude Code——在你终端里写代码、测代码、修代码的 AI

有些人还不知道可以用 Claude 写代码。不只是代码片段——是完整的生产级代码、整个功能、复杂的重构。你用大白话描述你要什么，Claude 写出来。

Claude Code 再进一步。它直接在你的开发环境里干活，不在聊天窗口：读你真实的代码库，写新代码，跑测试，读报错，然后修 bug，循环往复，直到任务完成。

它和 VS Code、JetBrains 集成。你还可以把它放进 GitHub Actions，它会自动审查或编写 PR（拉取请求），你什么都不用碰。

### 16. Claude Design——干视觉活的 AI

多数人不知道这个产品存在。Claude Design 是 Anthropic Labs 旗下一个独立的视觉工作工具：产品一页纸、融资演示稿、原型、落地页版式。

你描述你要什么，Claude 做出来。导出 PPTX、Canva、PDF 或 HTML。对不会设计的人来说，它把 3 小时的 Figma 会话换成 10 分钟的对话。

入口就在 claude.ai/design——直达链接，不需要额外步骤。

### 17. Prompt Caching——API 调用成本直降 90%（开发者向）

给在 Claude API 上做开发的读者。如果你的请求里有一大块重复的上下文——很长的系统提示词、一份参考文档、一个代码库——你每一次调用都在为重新处理同样的 token 付钱。

Prompt Caching 把那部分内容存在服务端。后续调用直接复用缓存，不再重新处理。缓存的 token 最高省 90%，响应也明显更快。如果你在规模化做事却没用这个，你正在白白扔一大笔钱。

**做法**：在你想要缓存的 content block 上加 `"cache_control": {"type": "ephemeral"}`。缓存保留 5 分钟，每次使用会重置计时器。适用于系统提示词、大文档和工具定义。

```
{
  "model": "claude-opus-4-6",
  "system": [
    {
      "type": "text",
      "text": "[你的长系统提示词或参考文档]",
      "cache_control": {"type": "ephemeral"}
    }
  ],
  "messages": [
    {
      "role": "user",
      "content": "[用户消息——每次调用都不同]"
    }
  ]
}

// 系统提示词在第一次调用后被缓存。
// 5 分钟内的每次后续调用都复用缓存。
// 缓存命中 = 便宜 90% + 响应更快。
```
