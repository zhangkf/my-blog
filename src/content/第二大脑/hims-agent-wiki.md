四月，Karpathy 写下了一种他称为 LLM Wiki 的模式：不要让智能体在每次提问时都去重读原始文档，而是让模型把它们一次性编译成 Markdown 页面，然后持续维护更新。

如今 agent wiki 这个概念已经无处不在——

- **Cognition 推出了 DeepWiki**：为每个公开的 GitHub 仓库生成一座 wiki（已收录五万多个），Devin 读 wiki 而不是原始代码。
- **Factory 做了 AutoWiki**：把文档当作构建产物对待，每次代码推送都在持续集成流水线里重新生成。
- **LangChain 开源了 OpenWiki**：从记录一个代码库，一路走到编译你的整个工作生活——Gmail、Notion、Git。
- **Garry Tan 开源了 GBrain**：个人规模的版本，就是放在 git 里的文件。
问题各不相同，答案却一再指向同一处：摄入时编译一次，维护好那些页面，然后读页面，而不是原始材料。

详细拆解每家做了什么、在哪里会失灵，见原文文章。
