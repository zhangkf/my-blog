用 OpenClaw 自带的基础记忆插件，总觉得小龙虾的记忆比较差，对话上下文一长之后，前面说过的重要信息很快就被遗忘。 刚好看到 memory-lancedb-pro 这个开源插件，专门用来强化 OpenClaw 长期记忆能力。 直接把检索机制提升到了生产级标准，不再是简单的模糊匹配， 并兼顾语义理解和关键词匹配，同时确保提取给 AI 的都是最新、最核心的信息。 甚至支持自我反思和纠错，让 Agent 在对话中不断优化自己的知识库。 GitHub：[github.com/win4r/memory-l…](https://t.co/Lda2uDRyiw) 兼容 Jina、OpenAI 以及本地 Ollama 等多种接口，配置非常灵活。 自带了完整的 CLI 命令行工具，方便我们在后台手动管理和审计记忆数据。 正在折腾 OpenClaw 小龙虾的朋友，这个插件值得一试。
